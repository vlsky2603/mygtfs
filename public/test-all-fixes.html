🚌 Тест исправлений симуляции автобусов

Ниже приведены шаги для проверки всех исправленных багов:

1. Скрытие радиуса при запуске симуляции

Ожидаемое поведение: При нажатии кнопки "Track" в расписании радиус остановок должен исчезнуть

Шаги:

  1. Кликните на любую остановку на карте
  2. В открывшемся расписании найдите кнопку "Track" возле любого маршрута
  3. Нажмите кнопку "Track"
  4. Радиус должен исчезнуть, центральный маркер тоже
Требует ручной проверки

2. Выделение остановки-старта

Ожидаемое поведение: При запуске live tracking остановка должна выделиться зеленым цветом

Шаги:

  1. Запустите live tracking (кнопка "Track")
  2. Остановка, с которой запущена симуляция, должна стать зеленой
  3. При наведении на остановку должен показаться попап "Live Tracking Start"
Требует ручной проверки

3. Корректная позиция автобуса по времени

Ожидаемое поведение: Автобус должен находиться на правильной позиции относительно времени прибытия

Шаги:

  1. Запустите live tracking для маршрута с автобусом через 30+ минут
  2. Автобус должен быть далеко от остановки, а не в середине маршрута
  3. Автобус должен двигаться в сторону остановки пропорционально времени
Требует ручной проверки

4. Устранение телепортации автобуса

Ожидаемое поведение: Автобус не должен скакать при наведении курсора

Шаги:

  1. Запустите live tracking
  2. Наведите курсор на движущийся автобус
  3. Автобус НЕ должен телепортироваться в случайное место
  4. Должна показаться информация о маршруте в попапе
Требует ручной проверки

5. Плавная анимация движения

Ожидаемое поведение: Автобус должен двигаться плавно по маршруту

Шаги:

  1. Запустите live tracking
  2. Наблюдайте за движением автобуса
  3. Движение должно быть плавным, без резких скачков
  4. Автобус должен следовать по линии маршрута
Требует ручной проверки

6. Корректная работа кнопки сброса

Ожидаемое поведение: Кнопка "Reset" должна возвращать радиус и очищать симуляцию

Шаги:

  1. Запустите live tracking (радиус должен исчезнуть)
  2. Нажмите кнопку "Reset" в правом верхнем углу
  3. Радиус и центральный маркер должны вернуться
  4. Все автобусы должны исчезнуть
  5. Зеленая остановка-старт должна исчезнуть
Требует ручной проверки
