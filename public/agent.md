🛰️ AGENT.md — Агент обработки данных GTFS
Этот проект — это веб-приложение на Node.js, предназначенное для отображения и взаимодействия с транспортными данными Winnipeg Transit. В составе проекта реализован агент, который обрабатывает GTFS-данные, обращается к внешнему API в реальном времени и отдаёт всё это во фронтенд в виде структурированных JSON.

🧠 Что делает агент
Фоновый агент (реализован в proxy.js и при необходимости в agent.js) отвечает за:

📥 Парсинг и загрузку GTFS-файлов:

stops.txt, routes.txt, trips.txt, stop_times.txt, shapes.txt, calendar.txt и другие

🧠 Преобразование данных в JSON для использования во фронтенде

🚀 Проксирование реального API Winnipeg Transit с безопасным доступом

📦 Кэширование тяжёлых операций

🌐 Отдачу структурированных данных по API для интерфейса карты

🌐 API-эндпоинты (через proxy.js)
Метод	URL	Назначение
GET	/api/stops	Возвращает все остановки
GET	/api/routes	Возвращает все маршруты
GET	/api/trips?route_id=42	Поездки по маршруту
GET	/api/stop_times?trip_id=abc	Время отправления/прибытия по поездке
GET	/api/shapes?shape_id=xyz	Геометрия линии маршрута
GET	/api/real_time?stop_id=1234	Живые данные прибытия от Winnipeg API

📌 Все ответы — в формате JSON, оптимизированы для фронта.

🧪 Правила разработки
Стили кода
4 пробела на отступ, никаких табов

Используй const и let, не используй var

Всегда ставь ; в конце строк

Одинарные кавычки: 'текст'

Лимит строки — 120 символов

Делай код модульным, сложные участки комментируй
