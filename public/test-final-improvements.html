ИСПРАВЛЕНО 1. Реалистичное позиционирование автобусов

✅ Автобусы теперь позиционируются на основе времени до прибытия:

  • 60+ минут: В самом начале маршрута (0-15%)
  • 30-60 минут: В первой трети (5-30%)
  • 15-30 минут: В первой половине (20-60%)
  • 5-15 минут: На основе скорости (60%+ маршрута)
  • 0-5 минут: Близко к остановке (80%+ маршрута)
ИСПРАВЛЕНО 2. Устранение скопления автобусов

✅ Каждый автобус получает уникальный сдвиг на основе своего ID:

const busIdHash = busId.split('').reduce((a, b) => { a = ((a << 5) - a) + b.charCodeAt(0); return a & a; }, 0); const uniqueOffset = Math.abs(busIdHash) % 30; const spread = (uniqueOffset % 6) - 2; // От -2 до +3 точек

🧪 Тестовые сценарии

Сценарий 1: Автобус через 45 минут

Ожидание: Должен появиться в первой трети маршрута

Логика: 30-60 минут = 5-30% маршрута

Сценарий 2: Автобус через 65 минут

Ожидание: Должен появиться в самом начале маршрута

Логика: 60+ минут = 0-15% маршрута

Сценарий 3: Несколько автобусов с одинаковым временем

Ожидание: Должны быть распределены, не накладываться

Логика: Уникальный сдвиг + spread на основе busId

Сценарий 4: Первая остановка маршрута + далекий автобус

Ожидание: Автобус не должен появляться слишком близко к остановке

Логика: Специальная корректировка для targetStopSequenceOnTrip <= 3

Сценарий 5: Запуск live tracking

Ожидание: Радиус поиска должен исчезнуть

Логика: opacity: 0 для radiusCircle и centerMarker

📝 Инструкции по тестированию

  1. Откройте главную страницу и найдите остановку
  2. Выберите маршрут с автобусами разного времени прибытия
  3. Запустите live tracking и проверьте:
    • Радиус поиска исчез
    • Автобусы появились в разных точках маршрута
    • Далекие автобусы (60+ мин) размещены в начале
    • Близкие автобусы (5-15 мин) близко к остановке
    • Автобусы не накладываются друг на друга
  4. Проверьте консоль браузера на предмет ошибок и логов позиционирования

⚠️ Известные ограничения

  • Позиционирование основано на математических расчетах, реальные автобусы могут отличаться
  • Для маршрутов с очень коротким shape может потребоваться дополнительная калибровка
  • Время в симуляции может отличаться от реального времени на несколько секунд
