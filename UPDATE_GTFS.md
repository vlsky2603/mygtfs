## Как обновить GTFS данные в будущем

### Способ 1: Через загруженный архив

1. **Скачать актуальные GTFS данные** с сайта Winnipeg Transit или получить через API

2. **Поместить архив** в корень проекта `/workspaces/mygtfs/`

3. **Выполнить команды:**
   ```bash
   cd /workspaces/mygtfs/public/gtfs
   rm -f *.txt
   unzip -o ../../ВАШ_АРХИВ.zip -d . "*.txt"
   ```

4. **Перезапустить сервер:**
   ```bash
   # Остановить старый процесс
   lsof -ti:8080 | xargs kill -9
   
   # Запустить новый
   node /workspaces/mygtfs/server/proxy.js > /tmp/server.log 2>&1 &
   ```

5. **Очистить кэш браузера:**
   - Способ 1: `Ctrl+Shift+R` (Windows/Linux) или `Cmd+Shift+R` (Mac)
   - Способ 2: F12 → Application → Clear storage → Clear site data
   - Способ 3: В консоли: `localStorage.clear()`

### Способ 2: Автоматическая загрузка из API (частичные данные)

Приложение автоматически загружает актуальные данные из API:
- ✅ Маршруты - из API (кэш 1 день)
- ✅ Остановки - из API по областям (кэш 7 дней)
- ✅ Расписания - из API в реальном времени
- ✅ Trips/Shapes - из локальных GTFS файлов

## Текущее состояние

### ✅ Все маршруты имеют полную поддержку:
- Линии маршрутов на карте (polylines)
- Симуляция движения автобусов
- Остановки и расписание в реальном времени
- Построение маршрутов (trip planning)

### Гибридный подход (API + GTFS):
- **Динамические данные** (маршруты, остановки, расписания) загружаются из API
- **Статические данные** (геометрия маршрутов, trips, shapes) берутся из локальных GTFS файлов
- Данные кэшируются в localStorage для быстрой загрузки

## Источники GTFS данных

### Официальный источник:
- Winnipeg Transit Open Data: https://winnipegtransit.com/en/open-data
- API документация: https://api.winnipegtransit.com/home/

### Через API:
```bash
curl -o gtfs_latest.zip "https://api.winnipegtransit.com/v3/gtfs?api-key=YOUR_KEY"
```
